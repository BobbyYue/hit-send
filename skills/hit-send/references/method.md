# 自然闭环沟通法：Agent 速查

## 一条公式

`来意 + 必要背景 + 我的判断 + 对方行动 + 时间或闭环`

这是发送前检查清单，不是必须逐项展示的模板。简单消息保留两三项，复杂协作再完整展开。

## 五个信息动作

1. **说来意**：让对方第一句就知道这是同步、求助、讨论、拍板还是风险。
2. **补背景**：只保留会改变优先级、范围、判断或责任的信息。
3. **给判断**：先完成自己职责范围内的分析，给倾向、依据或明确的不确定点。
4. **提行动**：明确谁做、做什么、何时完成、做到什么程度；不能按原计划完成时给协商出口。
5. **做闭环**：重要事项确认结论、负责人、时间和异常处理，并写回可追溯位置。

## 按复杂度裁剪

- **轻量**：状态或请求 + 必要时间。
- **常规**：来意 + 必要背景 + 行动 + 时间或回复方式。
- **完整**：结论或现状 + 背景 + 事实与判断 + 选项或建议 + 负责人、时间和闭环。

不要因为使用方法而把一句话扩成小报告。对方看完不需要追问“什么事、要我做什么、什么时候”，就不必继续加字。

## 先保留这句话原本要做的事

不是每句话都在推动行动。工作沟通还可能是在同步事实、表达异议、拒绝请求、指出前后差异、设置边界或留下记录。

- 原文没有请求，就不要为了“闭环”自动增加下一步。
- 原文在表达不满，就保留不满对应的事实和立场，不要只留下礼貌。
- 原文判断了他人动机时，不要把它改成另一个未经提供的结果事实。可以改成“我当时感受到……”，或只使用原文已经给出的可核验行为。
- 原文包含“现在 / 当时”“这次 / 之前”等对比时，保留这种对比，因为它通常就是作者要表达的核心。

当“保留立场”和“推动解决”会产生不同内容，而用户没有提供目的时，默认选择改动最小、最不新增含义的版本。备选版本只能调整直接程度或关系风险，不能凭空增加目标。

## 高摩擦沟通

### 分歧、催办和风险

先说已有事实与相关影响；原文或用户目标包含行动诉求时，再使用 `事实 → 影响 → 请求`：

- 事实必须能被核验，避免“总是、从来不、明显不重视”。
- 影响说明为什么现在处理，不夸大后果，不制造羞耻感。
- 请求只澄清已有的动作与必要时间，不新增期限、承诺或替代路径；仅表达异议、拒绝或同步事实时，可以没有请求。

重复叙述遮住重点时，提炼已有的变化、对照、条件、取舍或影响，并把影响理解的限定紧邻主句。只有真实且同维度的对比才使用平行句式，不制造对立、因果或赢家。对方能准确复述原意就结束，清楚的单个事实保持原样。例如“需求范围还没确定，目前无法给准确排期”不应自动加上“请今天确认”。

表达异议时，先对齐共同目标，再指出具体分歧、判断依据和替代方案。升级是为了引入决策或资源，不是公开追责。

### 自己情绪上来时

使用 `停、辨、译、选、发`：

1. **停**：高唤起时先不发送；紧急时只确认收到和下一次更新时间。
2. **辨**：分开感受、可核验事实和脑中的故事。
3. **译**：把评价转成事实、影响、关切和请求。
4. **选**：判断文字、私聊、短会或正式渠道哪个更合适。
5. **发**：删除动机判断、讽刺、反问和历史总账，只保留有助于解决问题的内容。

可以保留真实情绪，例如“我有些意外”“我担心影响明天的承诺”，但不能让情绪代替事实和行动。

如果原文只是表达态度，不要求采取行动，第 3 步应译成“事实、感受和立场”，不机械补请求。

### 收到情绪化表达时

使用 `接、拆、稳、界、落`：

1. **接**：承认着急、失望或业务影响，不急着接受不准确的指控。
2. **拆**：提取事实、情绪和真正请求，不逐句反驳。
3. **稳**：给确定动作和下一次更新时间。
4. **界**：说明愿意继续处理什么、不能接受什么、接下来换什么渠道。
5. **落**：确认事实、行动、负责人和书面结论。

持续辱骂、骚扰、歧视、威胁、报复或安全风险，不应仅靠措辞处理。保留记录并建议使用组织正式渠道。

## 什么时候不要继续改文字

建议切换渠道的信号：

- 异步往返两三轮仍不收敛；
- 涉及关系、动机、个人评价或公开冲突；
- 需要共同探索、复杂排障或实时权衡；
- 决策窗口短，等待回复的成本高；
- 内容敏感或需要正式留痕。

切换时仍给一条可发送的过渡消息，例如：

> 感觉文字里还有几个前提没对齐，我们拉 15 分钟把范围和时间定掉吧。结束后我把结论写回这里。

## 反模板规则

- 保留熟人之间的直接、简短和口语。
- 不机械添加“背景、结论、行动项”等标签。
- 不把每条消息都写成管理汇报。
- 不以更正式、更长作为更专业的替代品。
- 不隐藏明确责任、真实风险或合理边界。
